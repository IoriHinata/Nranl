# Полный индекс проекта

Рабочий проект романа «Город, который помнит нас». Вся документация находится в этой папке.

## Быстрый старт
1. Прочитать [паспорт проекта](00_PROJECT_BRIEF.md).
2. Изучить [исследование рынка](01_MARKET_RESEARCH.md) и [источники/методику](09_SOURCES_AND_METHOD.md).
3. Использовать [творческую библию](02_STORY_BIBLE.md) и [банк зацепок](03_HOOKS_AND_INSPIRATION.md) как источник вдохновения, а не обязательный сюжет.
4. Проверить конкурентные книги с помощью [CSV-шаблона](10_COMPETITOR_RESEARCH_TEMPLATE.csv).
5. Создать сильный фрагмент и собрать честную обратную связь по [шаблонам](08_TEMPLATES_AND_CHECKLISTS.md).
6. Начать продвижение по [плану](04_MARKETING_PLAN.md) и [календарю](05_LAUNCH_CALENDAR.md).
7. Записывать затраты и результаты в [бюджете/метриках](06_BUDGET_AND_METRICS.md).
8. Оценить риски в [реестре рисков](12_RISK_REGISTER.md).
9. Выбрать подходящий [путь публикации](13_RELEASE_PATHS.md).
10. Использовать [презентацию](07_PITCH_DECK.md) для переноса в слайды.

## Реалистичная цель
Не обещать успех выше 90%. Повышать вероятность хорошего результата через качество рукописи, проверку жанрового обещания, независимую обратную связь, правомерное продвижение и контроль расходов.
