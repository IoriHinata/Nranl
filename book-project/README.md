# Проект художественного романа

Рабочее название: «Город, который помнит нас». Жанровый ориентир: городское фэнтези / romantasy / мистический триллер.

## Материалы
- 00_PROJECT_BRIEF.md — цели, позиционирование и принципы проекта.
- 01_MARKET_RESEARCH.md — исследование рынка, факты, выводы и ограничения.
- 02_STORY_BIBLE.md — творческая основа, персонажи и правила мира.
- 03_HOOKS_AND_INSPIRATION.md — банк сюжетных зацепок и творческих упражнений.
- 04_MARKETING_PLAN.md — продвижение с минимальным бюджетом.
- 05_LAUNCH_CALENDAR.md — план на 30 дней.
- 06_BUDGET_AND_METRICS.md — бюджет и метрики.
- 07_PITCH_DECK.md — содержание презентации.
- 08_TEMPLATES_AND_CHECKLISTS.md — шаблоны и чек-листы.
- 09_SOURCES_AND_METHOD.md — источники и методология.

Никакой план не может честно гарантировать успех выше 90%. Цель папки — снизить риски, тестировать гипотезы дёшево и принимать решения на основе реальных реакций. Сюжетные материалы — вдохновение, не обязательная схема: автор сохраняет полную свободу.
