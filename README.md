# Nranl — рабочий архив проекта

Репозиторий предназначен для исходников, справочника мира и визуальных материалов проекта «Нранль».

## Документы
- [Канон мира](docs/CANON.md) — структурированный конспект предоставленного автором канона.
- [Каталог визуальных материалов](assets/README.md) — перечень файлов из архива «Крыло Армагеддона.zip».

## Правило канона
Авторские сведения считаются основными. Если факт не указан или есть противоречие, не додумывать его молча: отмечать вопрос и уточнять. Важное уточнение: Тлеющий Лес возник сам вокруг озера с плавающими трупами; под дном спит Столп Творения Чисаипеан II. Алекс его не создавал.
